# Test Seed Scripts

โฟลเดอร์นี้ใช้สำหรับเก็บสคริปต์การ Seed ข้อมูลเฉพาะส่วน เพื่อใช้ในการทดสอบระบบ หรือจำลองข้อมูลขึ้นมาแบบแยกส่วน โดยไม่กระทบกับการ Seed ข้อมูลหลักของระบบ

## คำสั่งสำหรับรัน Seed

คุณสามารถใช้ `pnpm tsx` ในการรันไฟล์สคริปต์ที่ต้องการได้โดยตรง เช่น:

### 1. ข้อมูลสินค้า (Products)

สร้างสินค้าจำลองแบบครบทุกช่อง (All Fields) จำนวน 4 รายการ

```bash
pnpm tsx scripts/seed-test/seed-products.ts
```

> **Note:** ตรวจสอบให้แน่ใจว่าไฟล์ `.env` มีการตั้งค่า `DATABASE_URL` อย่างถูกต้องก่อนรันคำสั่ง
