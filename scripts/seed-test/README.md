# Test Seed Scripts

โฟลเดอร์นี้ใช้สำหรับเก็บสคริปต์การ Seed ข้อมูลเฉพาะส่วน เพื่อใช้ในการทดสอบระบบ หรือจำลองข้อมูลขึ้นมาแบบแยกส่วน โดยไม่กระทบกับการ Seed ข้อมูลหลักของระบบ

## คำสั่งสำหรับรัน Seed

คุณสามารถใช้ `pnpm tsx` ในการรันไฟล์สคริปต์ที่ต้องการได้โดยตรง เช่น:

### 1. ข้อมูลสินค้า (Products)

สร้างสินค้าจำลองแบบครบทุกช่อง (All Fields) จำนวน 4 รายการ

```bash
pnpm tsx scripts/seed-test/seed-products.ts
```

### 2. ข้อมูลพนักงานขาย (Employees)

สร้างข้อมูลพนักงานจำลองจำนวน 4 รายการ (ประกอบด้วยพนักงานแบบทำงานอยู่ และลาออกแล้ว พร้อมข้อมูลส่วนตัว พื้นที่รับผิดชอบ)

```bash
pnpm tsx scripts/seed-test/seed-employees.ts
```

### 3. ข้อมูลลูกค้า (Customers)

สร้างลูกค้าจำลองครบทุกประเภท (DEALER, SUBDEALER, FARMER, BROKER) พร้อมเปิดฟิลด์เฉพาะตามประเภทลูกค้า จำนวน 4 รายการ

```bash
pnpm tsx scripts/seed-test/seed-customers.ts
```

### 4. ข้อมูลบริษัทขนส่ง (Shipping Companies)

สร้างบริษัทขนส่งจำลองจำนวน 4 รายการ (ใส่ข้อมูลสถานที่ ที่อยู่ โทรศัพท์ และสถานะใช้งานครบถ้วน)

```bash
pnpm tsx scripts/seed-test/seed-shipping-companies.ts
```

### 5. ข้อมูลเป้าหมายการขาย (Sales Targets)

สร้างข้อมูลเป้าหมายประจำเดือนของพนักงานแบบครบถ้วน (ประกอบด้วยตาราง `SalesTarget`, ลิงก์ร้านค้ารายเป้าหมาย `SalesTargetStore` และรายการแยกรายสินค้า `SalesTargetItem`)

> **สำคัญ:** โปรดตรวจสอบว่ามีข้อมูลพนักงาน, ลูกค้า และ สินค้าในระบบแล้วก่อนเรียกใช้งานสคริปต์นี้

```bash
pnpm tsx scripts/seed-test/seed-sales-targets.ts
```

### 6. ข้อมูลการขาย (Sales & Orders)

สร้างข้อมูลใบสั่งขาย (Sale) จำนวน 1 รายการ แบบอัดแน่นครบทุกฟิลด์ มีทั้ง `SaleItem` เก็บราคาสแนปช็อต, `SaleAddress` แยกที่อยู่จัดส่งและที่อยู่วางบิล รวมถึงประวัติอัปเดตสถานะ `SaleStatusHistory` ให้ทั้งหมด (สมมติว่าเป็นใบสั่งซื้อที่ **อนุมัติแล้ว** และให้เครดิต)

> **สำคัญ:** ต้องมีข้อมูลพนักงาน, ลูกค้า, สินค้า, (และสามารถมีบริษัทขนส่ง) พร้อมกับระดับระบบล๊อกอิน User ก่อนรันสคริปต์นี้

```bash
pnpm tsx scripts/seed-test/seed-sales.ts
```

> **Note:** ตรวจสอบให้แน่ใจว่าไฟล์ `.env` มีการตั้งค่า `DATABASE_URL` อย่างถูกต้องก่อนรันคำสั่ง
