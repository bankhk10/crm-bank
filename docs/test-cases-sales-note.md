## Test Environment Requirements

1. **Database**: ต้องมีข้อมูล Master Data (ลูกค้า, สินค้า, พนักงาน)
2. **Users**: ต้องมี User หลายระดับสิทธิ์

5. **Concurrency Testing**: ต้องใช้ Load Testing Tool (JMeter, k6)
